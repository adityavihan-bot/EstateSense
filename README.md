# 🏠 EstateSense – Property Price Prediction App

EstateSense is a Machine Learning-based web application that predicts the prices of real estate properties such as houses, flats, and land based on user inputs. The application uses regression techniques to estimate property prices using key features like area and number of bedrooms (BHK).

Built with Python and deployed using Streamlit, the app provides a simple and interactive interface where users can input property details and instantly receive an estimated price.

## 🚀 Features

* Predict prices for House, Flat, and Land
* User-friendly interface built with Streamlit
* Real-time price prediction using Machine Learning
* Handles different property types dynamically
* Clean and responsive UI

## 🧠 Machine Learning

The model is trained using Linear Regression from scikit-learn, utilizing features such as:

* BHK (number of bedrooms)
* Area (in square feet)

## 🛠️ Tech Stack

* Python
* Pandas & NumPy
* Scikit-learn
* Streamlit

## 📌 Use Case

This project can help users get a rough estimate of property prices, making it useful for buyers, sellers, and real estate enthusiasts.
